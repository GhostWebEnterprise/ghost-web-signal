GhostWeb VPN

A privacy-focused Chromium proxy client designed to route browser traffic through your own endpoint while adding browser-level privacy protections.

Latest release · v1.0.0All releases

Private browser routing with SOCKS5 support, location protection, timezone spoofing, WebRTC hardening and self-hosted endpoint support.

Download v1.0.0 ZIP ↗Release notes ↗
🔌

Proxy routing

Browser traffic can be routed through HTTP, HTTPS, SOCKS4 or SOCKS5 endpoints.

🌍

Location protection

Geolocation, timezone, Date and Intl surfaces can follow the active route.

🚫

Self-hosted

No bundled VPN servers. Use an endpoint you control and verify it before browsing.

Chrome installation: download the release ZIP → extract it → open chrome://extensions → enable Developer mode → choose Load unpacked → select the extracted GhostWeb VPN folder. Configure your endpoint and run the health check before browsing.
